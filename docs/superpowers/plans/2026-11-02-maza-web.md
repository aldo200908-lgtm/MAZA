# MAZA Web Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
**Goal:** Publicar la web MAZA con área pública y administrativa independientes.
**Architecture:** go_router con ramas persistentes; WebController coordina sesión, catálogo y reservas. Gateway separa demo persistente de RPC Supabase. Admin reutiliza AppStore y formularios existentes.
**Tech Stack:** Flutter 3.35.7, go_router 16.2.4, Supabase Flutter 2.8.4.
**Spec:** docs/superpowers/specs/2026-11-02-maza-web.md
## Global Constraints
- Solo web, español, PEN, Perú, celular primero. Publicar en MAZA/GitHub Pages autorizado en el hilo.
- Cuentas y roles reales por Supabase; demo explícita. Sin pagos reales ni nuevos datos personales públicos.
## Review Focus
- Acceso directo /admin sin autorización y cierre de sesión con rutas abiertas.
- Reserva conservada al pasar por acceso/perfil, turno ocupado y doble envío.
- Catálogo anónimo nunca expone clientes, notas o reservas ajenas.
- Cancelar/reprogramar requiere cita propia, futura, estado permitido y versión vigente.
- Rutas inexistentes, historial vacío, recarga y pantallas de 360px con texto ampliado.
