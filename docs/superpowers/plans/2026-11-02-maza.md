# MAZA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Demo navegable Flutter, módulos Base, Citas y Barbería, con Supabase y SQL de cinco módulos operativos.
**Architecture:** Modelos compartidos y repositorio con dos adaptadores. UI por módulos. El servidor impone acceso y disponibilidad.
**Tech Stack:** Flutter 3.35.7/Dart 3.9, Supabase Flutter 2.8.4, shared_preferences, uuid.
**Spec:** docs/superpowers/specs/2026-11-02-maza-design.md

## Global Constraints
- Español, PEN, móvil primero; un administrador; sin cobros reales.
- Stock/Alquileres/Pagos vacíos; modo demo explícito; SQL con RLS.

## Review Focus
- Solapamientos concurrentes y reservas contiguas: exclusión SQL [inicio, fin).
- Horarios por día y Perú: validación de intervalos completos en cliente/servidor.
- Cambios de precio/duración: conservar instantánea histórica.
- Usuario autenticado no autorizado: cero acceso; no autorregistro.
- Reinicio demo y fallos de escritura: persistencia y mensajes sin perder estado confirmado.
